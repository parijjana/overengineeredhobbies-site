A minimalist, distraction-free writing application designed for creative flow. Features a translucent "Ghost UI" and seamless versioned cloud sync via Google Drive.

CORE PHILOSOPHY

Pellucid eliminates UI clutter to focus entirely on words, while providing structured research management through a bidirectional connection graph.

SYSTEM ARCHITECTURE

Markdown Editor (Custom Controller)
  ↓ auto-saves
SQLite (Local) + Google Drive (Cloud)
  ↓ synced
Research Notes (Bidirectional Graph)

KEY CAPABILITIES

• Ghost UI: Low-contrast, highly-transparent interface for deep focus.
• Versioned Sync: Automatic manuscript snapshots and cloud restoration points.
• Knowledge Integration: Side-by-side research notes with automated attribution.
