THESIGN

A minimalist 2D puzzle-platformer rendered in the style of public-safety signage. Features symbolic gameplay where mechanics are taught without written language.

CORE PHILOSOPHY

Designed with "Kindness by Design," The Sign eliminates death and punishment, focusing on accessible, non-lethal physics challenges for all ages.

SYSTEM ARCHITECTURE

Flame Game Loop
  ↓ manages
Level Pipeline (JSON Nodes)
  ↓ triggers
Claw Reset / Puzzle Scripts

KEY CAPABILITIES

• Symbolic Gameplay: Wordless environment using universal signage visuals.
• Forgiving Mechanics: Kinematic movement with non-lethal failure resets.
• Educational Puzzles: Physics-based challenges covering mechanics and optics.
