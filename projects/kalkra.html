A high-performance mental math trainer with a custom-built solving engine. Players combine a pool of numbers using arithmetic operators to reach a target — but every puzzle is verified solvable before it appears. The engine runs two solvers: a recursive early-exit tree search for speed, and a bitmask DP exhaustive solver for modes that require knowing the complete reachable set.

CORE PHILOSOPHY

Every puzzle in Kalkra is mathematically guaranteed solvable before it reaches the player — the solver architecture exists to make that promise cheap to keep at runtime. The app is offline-first: zero network calls, no accounts, no telemetry by default. Career data and stats are protected by AES-256-CBC + HMAC-SHA256, with encryption keys stored in platform secure storage (iOS/macOS Keychain, Windows credential store), making saves hardware-backed and tamper-evident.

SYSTEM ARCHITECTURE

Number Pool (6 integers)
  ↓ ExhaustiveSolver (bitmask DP, all 2^N subsets)
Reachable Value Set
  ↓ SolverEngine (recursive early-exit tree search)
Verified Target(s)
  ↓ MatchManager (pre-computed, isolate-offloaded)
Game Round (numbers + target + wildcard modifier)
  ↓ Submission Validator
Score / Next Round
  ↓ flutter_secure_storage (AES-256 + HMAC-SHA256)
Career & Stats (hardware-backed, tamper-evident)

KEY CAPABILITIES

• Dual Solver Architecture: recursive early-exit search + bitmask DP exhaustive solver — every puzzle is verified solvable before it appears.
• Solvability-Guaranteed Modes: Triple Threat (3 of 9 solvable) and Double Danger (2 of 4 solvable) use the exhaustive solver to deliberately place unreachable decoys.
• Pre-computed Matches: all rounds generated and verified in background isolates before play starts — zero loading mid-match.
• Adaptive Difficulty: target range and lives scale dynamically; Progressive mode runs a fixed ladder of named round configs.
• Tamper-Evident Saves: AES-256-CBC + HMAC-SHA256 local storage, keys in platform secure storage (Keychain / Windows credential store).
