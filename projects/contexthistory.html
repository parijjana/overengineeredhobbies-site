ContextHistory is an evolutionary memory infrastructure for AI agents. It tracks, stores, and evolves project context over time, allowing agents to "remember" architectural decisions, engineering preferences, and past breakthroughs across multiple sessions.

CORE PHILOSOPHY

By treating context as a living entity that needs to be distilled and archived, ContextHistory prevents information rot and agent amnesia. It provides a standards-compliant MCP server that integrates seamlessly with Gemini CLI, Claude, and Cursor, featuring automated environment validation and sandbox repair.

SYSTEM ARCHITECTURE

AI Agent (Gemini/Claude)
  ↓ MCP Tools
Librarian (Parser/Distiller)
  ↓ manages
Memory Databases (Archeology/Orchestration)

KEY CAPABILITIES

• Context Archeology: Automatic recovery and injection of relevant historical context into active sessions.
• Semantic Distillation: Compression of verbose session logs into concise architectural insights.
• Governance & Repair: Automated conflict resolution and environment restoration for broken sandboxes.
